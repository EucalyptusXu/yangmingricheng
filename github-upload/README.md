# 阳明日程

**把王阳明，放进你每天的待办里。**

它不是名人名言 App，也不是普通的日程工具。它做的是：你今天要做什么、你做完多少、你现在的状态是什么 —— **用一句话、一段话、一首诗，把王阳明对位到你今天的生活里。**

没有云端。419 条语录全在本地。**装完断网也能用，也什么都不上传。**

---

## 这几个瞬间你会感受到它不一样

### 1. 你累了的时候，它不教训你

你下班回家，今天还有两件事没做完。打开 App，顶部那句话不是"志不立天下无可成之事"。

**它会站在你这边。**

不是"鸡汤"——是王阳明自己说的"事变亦只在人情里"、是"良知只在见在，更无去来"。

怎么做到的：语录有三种语气——**律己**（在要求你）、**体谅**（在理解你）、**说明**（把事情讲明白）。当判断你今天状态偏沉、而你又没有主动表达"我今天要振作"，引擎会**硬排除**所有律己语录。这是底线，不是加权。

> 加权做不到"绝不"这个保证。所以这里是硬过滤。

### 2. 你刚写了"产品评审会"，它告诉你首页会变

添加日程时，输入标题的瞬间，页面会实时预览首页那句会变成什么。

不是"加载中"的模糊提示 —— 是**等你写完那句话之后**给你看：这一句，配你这件事，**它懂**。

### 3. 早上 7:30，不用打开 App，先看到一句对的话

打开 App 之前，通知栏先弹一条："今日一句 · 传习录"。轻点的，**没有"稍后提醒"按钮**，不和日程提醒抢优先级。

默认 07:30。在「我的 → 设置」里可以关，也可以改时间。

### 4. 你说"今天不想听这句"，它换得理直气壮

每条语录下有两个按钮：
- **「说得对」** —— 今天不再给这句
- **「今天不想听这句」** —— 立刻换，且这句今天不再出现

负反馈是**立即生效**，不是排队等你下次开 App。

### 5. 朱砂"王"字在右上角等你

打开 App，右上角一个**印章样式的 logo**。每条语录下方是篇名（"传习录·徐爱录"这种）。点击可以看完整语录库，10 个主题筛选、可搜索。

## 419 条语录，全是王阳明

按来源分四册：

| 来源                         | 条数      |
| -------------------------- | ------- |
| 《传习录》《大学问》《教条示龙场诸生》《示弟立志说》 | 150     |
| 书信、杂著、序记、乡约、《传习录》补遗        | 126     |
| 诗作（据《王阳明全集》诗部）             | 127     |
| 补遗：补稀薄标签                   | 16      |
| **合计**                     | **419** |

三种语气分布：**律己 35% / 体谅 41% / 说明 24%**。

这个比例是**刻意配的**——原版本律己占 56%，你下班累到不想动时打开看到"志不立天下无可成之事"，那不是被鼓励，是被指责。现在不会了。

## 你能拿它来做什么

- **添加日程**：标题、日期、起止时间、备注、重复规则（每天 / 工作日 / 每周 / 每月）、提前多久提醒
- **日程提醒**：准时或提前 5/10/15/30/60 分钟发通知，**通知正文就是那句对位的语录**
- **逾期顺延**：今天发现昨天有事没做？今日页顶部会列出来。单条"已做 / 顺延到今天"，或者一键全部顺延，**带撤销**
- **看日程**：日历页有四种视图——
  - **日**：今天要做的事，按时间排
  - **周**：七天完成度柱状
  - **月**：格子日历，每格圆点是完成度
  - **年**：365 天热力图 + 12 个月缩略
- **看数据**：年度总数 / 已完成 / 完成率、连续达标天数、近 30 天趋势、事项标签分布
- **看语录库**：按 10 个主题筛选、按关键词搜索
- **导出 / 导入备份**：换手机不丢东西

## 数据存在哪

**你手机的本地。**

应用**没有网络权限**——根本不能联网。所以：
- 不会上传任何服务器
- 换手机：「我的 → 导出备份」复制那串 JSON，新机器「导入备份」粘回去
- 首次运行的演示数据**不会自动塞**，要先在引导卡片上点"先用示例看看"；之后顶部有个一键清空按钮，**只删示例、不动你自己加的数据**

## 怎么装到手机上

### 路径 A：你有 Android Studio

打开 `android/` 目录 → 等 Gradle 与 SDK 下载完 → Build → Build Bundle(s) / APK(s) → Build APK(s)。

产物：`android/app/build/outputs/apk/debug/app-debug.apk`

### 路径 B：你什么都没有

推上 GitHub 之后，仓库里的 `.github/workflows/build-apk.yml` 会自动跑云端打包。

3~5 分钟，进 **Actions** 拿 **Artifacts** 下载。**Artifacts 需要登录 GitHub 才能下载**——想发给别人：在仓库里建一个 Release，把 apk 当附件传上去。

## 装好之后必做的两件事

1. **「我的」页 → 申请通知权限**（系统会弹窗）
2. **点「测试提醒」**，确认通知栏真的能弹出来

没弹？按这个顺序排查：
- 系统设置 → 应用 → 阳明日程 → 通知：是不是被关了
- 系统设置 → 电池 → 应用启动管理：设为「手动管理」并允许后台活动（**国产 ROM 默认会杀后台**，这是提醒失效最常见的原因）
- Android 12+：设置 → 应用 → 特殊权限 → 闹钟和提醒 → 允许（这个没开也只是时间会飘，不会丢）
